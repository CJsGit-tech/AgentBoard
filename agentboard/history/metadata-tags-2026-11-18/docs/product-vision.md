# Product Vision — AgentBoard

> Owner: Product Manager | Version: 0.1.2 | Status: draft | Last Updated: 2026-11-17

## Product Overview

AgentBoard is an app that helps solo builders manage AI agents and product projects in one place. It brings together agent roles, tasks, product documents, and progress tracking so builders can coordinate responsibilities, keep project context organized, and understand what needs attention as they move a product forward.

## PainPoints

- Project information scattered across conversations and tools makes context difficult to find.
- Unclear agent responsibilities make work assignments and handoffs harder to coordinate.
- Disconnected tasks and documents make it difficult to relate work to its supporting decisions and outputs.
- Limited visibility into progress and blockers makes it harder to decide what to do next.
- Managing several agent roles and product projects adds coordination work for a solo builder.

## Features & Value Proposition

**Product project management**

- Organize each product's purpose, work, and documents in a shared project workspace.

**Agent role management**

- Define responsibilities and associate agent roles with project work so ownership is clear.

**Task coordination**

- Create, prioritize, assign, and track tasks to keep work organized and handoffs clear.

**Document management**

- Keep product documents and task outputs connected to the work they support, making context easier to find.

**Progress tracking**

- See active work, completed tasks, and blockers to identify what needs attention next.
